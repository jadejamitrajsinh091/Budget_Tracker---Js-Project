# 💰 Budget Tracker System

This project is a simple and responsive **Budget Tracker System** built using HTML, CSS, JavaScript, and Bootstrap 5.

The application allows users to add a budget, add expenses, remove expenses, and view the remaining budget dynamically.

## 📋 Main Functions

### Add Budget

Users can enter a budget amount and add it to the tracker.

### Add Expense

Users can enter:

- Expense Name
- Expense Amount

The expense is then dynamically added to the Expense History table.

### Remove Expense

Individual expenses can be removed from the table, and the total expense is updated automatically.

### Reset All

The Reset All button clears the expense history and resets the budget and expense values.

## ▶️ How to Use

1. Enter your budget amount.
2. Click **Add Budget**.
3. Enter the expense name.
4. Enter the expense amount.
5. Click **Add Expense**.
6. View the updated Total Expenses and Budget Left.
7. Use **Remove** to delete an individual expense.
8. Use **Reset All** to clear the tracker.
